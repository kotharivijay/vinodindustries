3 · What changed vs the earlier version

Old — dropdown popover
  • Attached to the 🎯 Party button
  • Small width, opens downward, sensitive to viewport edges
  • Page underneath fully visible & interactive (accidental clicks possible)
  • Mobile: overlays the input awkwardly
New — separate window
  • Own modal centred on screen (desktop) / bottom sheet (mobile)
  • Dim backdrop — page behind is greyed out so the picker is the only thing you can touch
  • × close button, ESC key, backdrop click all dismiss
  • Wider — party names never truncate; despatched + inward numbers fit comfortably
  • Body scroll is locked while open (no accidental page scroll)
  • Same layout on both modules — only colours + row content differ
