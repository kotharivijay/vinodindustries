Definitions: a batch is 🏁 done when its dye slip's than is fully claimed by finish entries; ⏳ pending (amber) = dyed but finish not complete; pending (gray outline) = no dye slip yet.

Variant A — chips always visible; when >6 done batches, the green list auto-collapses to ranges (“B14–B27”) to stay one-line-ish. Best for scanning.

Variant B — compact “18/20 done” + progress bar, chips on tap. Quieter, but hides the batch numbers the user asked to see.

Suggested: A with the range-collapse. Needs /api/fold (or /api/fold/validate-style side endpoint) to return per-batch finish status: join dyeingEntries → finishEntryLot sums per batch.
