JWPCTT — Goods Received by member units mockup

Jasol Water Pollution Control And Treatment Trust has 74 connected units. Each unit signs up with its firm name, a login ID and a password; a JWPCTT authoriser approves the request. Approved units then record every consignment of goods received at their factory (Date · Transport · LR No · Bales) — from mobile, desktop or by uploading the Excel template. The entry form auto-saves a draft so nothing is lost before Save. Each unit sees its own weekly / monthly / yearly dashboard; the admin sees every unit and builds a combined report.

Smart-upload rules
  • Header check first — wrong / renamed columns stop the upload with "Download the template again".
  • Normalise before comparing — LR "LR-4402", " 4402 ", "4402/A" are shown as possible matches (amber), exact matches as duplicates (red).
  • Transport names fuzzy-matched to the unit's existing transports ("jasol roadways" → "Jasol Roadways"); new names are created and listed in the summary.
  • Nothing partial — the file is saved in one go after confirm; Undo removes exactly that batch (10-minute window).
  • Every saved row stores file name + upload time for audit; admin can see "from Excel" vs manual.
  • Same check on manual entry — typing an existing LR shows the inline warning (see 4 · A).

Notes / decisions to take before building

1 · Where does it live?

Units need ID + password + approval. The existing Vinod Industries app is Google-login only with an env-var allowlist and has no user table. Two options:

  • Standalone app (own Vercel project + DB, like rahul_shades) — cleanest; JWPCTT admin logs in there.
  • Module inside this repo under /jwpctt — reuses Drive / WhatsApp helpers but needs a credentials provider + JwpcttUnit table added.

Recommend: standalone.

2 · Draft autosave

Keystroke-level save to the device (localStorage / IndexedDB, keyed by unit) — instant and works offline. Sync to a server draft row on field blur so a unit can continue from another device. Draft removed on Save.

3 · Duplicate key

LR No + Transport within a unit. Also warn (not block) if the same LR appears at another unit — useful for JWPCTT audit.

4 · Fields to confirm

  • Is No of Bales enough, or also weight (kg) / goods type (grey / yarn / chemicals)?
  • Edit / delete window for units (mockup says 7 days) — or admin-only?

5 · Roles

  • Unit — own entries + own dashboard.
  • Authoriser — approve / reject / deactivate units (may be same person as admin).
  • Admin — everything + combined reports + WhatsApp reminders to units with no entry.

Sign-up notifications: WhatsApp to authoriser on new request; WhatsApp to unit on approve / reject.
